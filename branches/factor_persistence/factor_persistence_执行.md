## 分支G - 修正"有苗头"标准

### 决策依据

原标准"概率>50% + t>2"要求"稳定超额"，但老板要的是"承担系统性风险（高收益低稳定）"。稳定超额=镜花水月。

### 新标准

**有苗头 = t绝对>2（不是运气）+ 低稳定（概率~50% 波动大）= 承担系统性风险有溢价**

- t绝对>2：赚钱不是运气（低波 2.84 ✓）
- 概率~50%：低稳定（高收益低稳定 = 承担系统性风险特征）
- 不需要概率>50%（那是"稳定超额"=镜花水月）

### 低波符合新标准

| 指标 | 低波值 | 判定 |
|------|--------|------|
| t绝对 | +2.84 | ✓ 不是运气（p<1%） |
| 月概率 | 50.0% | ~50% 低稳定 |
| 周概率 | 42.2% | ~50% 低稳定 |
| 高收益 | +1.29%/天 | ✓ |
| 低稳定 | 月超额波动 0.05 | ✓ |

低波 = 承担系统性风险（低波风险因子有溢价但不稳定）。**这正是老板要的"高收益低稳定"策略。**

## 最终结论

### 策略雏形

**低波 Top10 T+20 + 回测过滤（ST/退市/流动性）**：
- **承担系统性风险**：低波风险因子（t>2 不是运气，有溢价）
- **规避非系统性风险**：ST/退市/流动性过滤（个股风险）
- **高收益低稳定**：概率~50%（承担风险特征，不追稳定超额）

### 尺子使用

1. **t绝对>2**：判断"不是运气"（承担系统性风险有溢价）-- 不追 t超额>2（镜花水月）
2. **切片概率~50%**：低稳定（承担系统性风险特征）-- 不追>50%（稳定超额=镜花水月）
3. **回测过滤**：规避非系统性风险（ST/退市/流动性）

### 其他分支（记录未走）

- B（38因子）：低波已"有苗头"，38因子可后续扩展找更多苗头，但非必需

- E（组合因子）：低波+反转 combo 之前夏普1.13（不如纯低波），不优先
- F（调Top/horizon）：Top10 T+20 已最优（6组对比验证），不调

### 过程总结
