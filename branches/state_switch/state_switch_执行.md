## 发散方向：全因子多周期延续性

根据验证结论发散（老板和 DS 讨论，cc 整理）：

### 核心思路

不找"全时段最优"策略，找"**因子统计学延续性**"：
- 因子在多周期（周/月/季）都最优 = 延续性强（不同时间尺度都好）
- 只在某周期零星 = 延续性弱
- 用多周期最优频次作统计证据

### 低波例子

低波：月14/季6/半年3/年2 = 多周期都好 = 延续性强。动量：月6/季2/年0 = 弱。

### 推广到全部因子

1. 38 因子（+融资融券+成交量）多周期切割
2. 每因子选 Top10 + T+收益，周/月/季/半年/年
3. 多周期最优频次 = 延续性证据
4. 分批跑（凌晨，断点续传，结果累积）
5. 最终汇总：哪些因子延续性强

### 实施建议

- 分步：先几个关键（低波/反转/动量+融资融券+成交量），再 38 全量
- 分批：凌晨跑，断点续传，结果放一起分析
- 如果要跑，新开 `branches/factor_persistence/` 验证通道

- 换评估标准（夏普/盈亏比）有效，但 2026 是普遍难点
