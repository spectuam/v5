## 零、这份文档的用途

记录"v5 应该是什么、按什么原则搭"的第一个假设。本文对每个参考系统都附**它是干嘛的**的说明——因为参考系统只有名字的话，过段时间就不知道它是什么了。

## 一、目标假设（假设 #1）

**搭积木**：用市面成熟系统的零部件，搭一个提升个人市场收益率的量化系统。

资源约束两条：
1. 自有资源（现有数据、脚本、人力）
2. 未来个人能力能获取的资源——**开放且收益能覆盖成本**的

推论：只消费"成本 < 收益"的产出；决策核心必须自建。

## 二、市面量化系统七类分类（按目的，非按环节）

为什么按目的分：按环节（执行/研究/回测）分各系统重叠严重；**按目的分——最终产出物是什么、为谁的决策服务——决定了系统内各模块的设计思路**。同一执行序列的模块（如回测），因目的不同设计完全不同。

分类判据：**系统的最终产出物只有七种，没有第八种**——数据 / 候选集 / 模型 / 证据 / 订单 / 风险视图 / 信号内容。产出物穷尽，分类即穷尽。

---

### F 数据供应系统

- **产出物**：数据（行情 / 基本面 / 另类数据）
- **决策者**：消费方系统（所有量化系统的输入源）
- **模块设计服从**：数据广度、时效、point-in-time 质量（免幸存者偏差）、API

**代表系统（是干嘛的）**：
- **Wind（万得）**：国内机构标配金融数据终端，行情/财务/宏观全覆盖，年费数万元级，个人基本无法开通。设计质量是行业标杆（PIT 数据），但成本远超个人可负担线
- **Bloomberg（彭博）**：国际机构标配终端，年费约 3 万美元，附带新闻/聊天/交易功能。个人不可能
- **iFinD（同花顺机构版）**：同花顺的机构数据终端，比 Wind 便宜但仍属机构级
- **Quandl（Nasdaq Data Link）**：国际数据市场，部分免费、部分付费
- **RavenPack**：新闻情绪/另类数据商，机构价
- **免费开放侧（我们在用的）**：AKShare / Tushare（免费开源数据接口）、TDX（通达信本地数据）——v5 的数据管道（kline_15m）就建在这上面

**对 v5**：只拿结果（免费开放源），参考设计思路（PIT 质量）。机构级数据选择性无视（成本 > 收益）。

---

### D 挖掘系统

- **产出物**：经过评估**录用**的候选集/因子集
- **决策者**：人（PM/平台录用）
- **模块设计服从**：候选吞吐量（海量候选）、批量快速评估、相关性去重、录用门槛、人工复审（经济含义）

**代表系统（是干嘛的）**：
- **WorldQuant WebSim**：全球知名量化对冲基金世坤投资（WorldQuant）的公开"挖因子"平台。全球任何人（尤其发展中国家人力）在上面写 alpha 表达式，平台自动回测评估（Sharpe、Fitness、换手、相关性），设提交门槛，**录用者进入该基金的实盘因子池**，挖矿者获奖励或咨询职位。平台的评估流程公开可见，但录用因子归平台所有
- **QuantConnect Alpha Stream**：众包策略平台。用户提交策略，平台用一套统计指标自动评估（Sharpe/PSR/回撤/容量），入选策略获得配资运行。其 LEAN 引擎是开源的
- **机构 alpha 工厂**：各大对冲基金内部自研（不可见）

**对 v5**：产出物拿不到（录用因子归平台），只能**参考设计思路**——批量评估流水线、录用门槛、相关性检查。v5 现在缺的恰好是这端（候选池小、搜索弱）。

---

### C 模型系统

- **产出物**：收益预测模型（可滚动重训、可上线）
- **决策者**：模型（自动决策）
- **模块设计服从**：数据管道、训练流水线、实验管理、滚动重训（rolling retrain）

**代表系统（是干嘛的）**：
- **Qlib**：微软开源的 ML 量化平台，免费完整流水线：数据 → 特征（Alpha158/360 因子库）→ 模型（LightGBM/GRU/LSTM/Transformer 等预实现）→ 回测 → 滚动重训。v5 已在使用其数据转换与训练模块（build_qlib_binary / train_lightgbm / full_pipeline）
- **BigQuant**：国内 AI 量化 SaaS 平台，图形化 + 代码

**对 v5**：Qlib 开源，**拿部分模块直接用**（零成本）。产出物（别人训练好的模型）不存在，只能自己训练。

---

### B 证据系统

- **产出物**：研究结论/证据（"这个策略行不行、可不可信"）
- **决策者**：人（研究员）
- **模块设计服从**：回测保真、统计检验（CPCV/DSR/PSR）、报告可视化

**代表系统（是干嘛的）**：
- **聚宽 / 米筐**：国内在线量化研究平台，数据+回测+模拟盘+社区，个人免费档可用。产出的是"平台内策略的证据"，不对外
- **Statistica AI**：商业量化研究平台，卖给机构，内置 walk-forward / CPCV / deflated Sharpe 验证
- **ml4t-diagnostic**：开源库，实现 CPCV / DSR / PBO（回测过拟合概率）检验，免费
- **purgedcv**：开源库，sklearn 兼容的净化交叉验证（purging + embargo）
- **Backtrader**：经典开源回测框架（事件驱动）

**对 v5**：方法论（CPCV/DSR）开源，v5 已自建评估器（compare_pool / walk-forward / forward tracker / param_scan）——**这是 v5 的自建核心**。开源库（ml4t/purgedcv）可作为模块补给。

---

### A 执行系统

- **产出物**：交易订单/成交
- **决策者**：机器 + 券商
- **模块设计服从**：低延迟、稳定性、风控合规、成交保真。策略是输入不是产出

**代表系统（是干嘛的）**：
- **QMT（迅投 MiniQMT）**：券商提供的量化交易终端，Python 接口，可免费开通（需券商账户，通常有资金门槛），提供实时行情 + 实盘下单
- **PTrade**：恒生的量化交易终端，券商提供，类似 QMT
- **XTP（中泰证券）**：极速交易柜台接口，面向量化，速度快
- **机构 OMS**：机构内部订单管理系统（不可见）

**对 v5**：**只拿结果**——用 QMT 免费成交通道，不自建。自建券商连接/低延迟是负收益工程（那是券商的问题，不是我们的问题）。

---

### E 风控系统

- **产出物**：风险视图 / 组合分配 / 合规告警
- **决策者**：组合经理 / 风控人员
- **模块设计服从**：风险模型（因子归因）、限额、监控

**代表系统（是干嘛的）**：
- **Aladdin**：贝莱德（BlackRock，全球最大资管）自研的组合+风控+交易平台，管理其十万亿美元级资产，不对外
- **Barra**：MSCI 的风险模型（多因子风险分解），机构订阅
- **Axioma**：另一家风险模型商，机构订阅
- **开源替代**：pyfolio / empyrical（回撤、风险指标计算）

**对 v5**：机构产品贵且个人需求简单，**参考设计思路 + 轻量开源模块**，风控规则自建（我们已有 MDD/Calmar/DSR 评估）。

---

### G 信号平台

- **产出物**：信号/内容（可消费的决策输入）
- **决策者**：散户
- **模块设计服从**：社区生态、低门槛、图表交互

**代表系统（是干嘛的）**：
- **TradingView**：全球最大图表/指标/策略社区，写指标分享信号，可连接券商跟单
- **etoro**：社交跟单平台，复制他人交易
- **雪球**：中文投资社区，组合/观点分享

**对 v5**：**选择性无视**（作为消费者）——买信号 = 把决策外包给信息劣势方。唯一例外是认知文档 §八：把外部策略（社区/论坛）当**候选**喂进来比较——那是 D 的供给端用法，不是消费信号。

## 三、积木决策矩阵（假设 #1 的核心）

| 类 | 利用方式 | 拿什么 | 依据 |
|---|---|---|---|
| A 执行 | **只拿结果** | 成交通道 | QMT 免费开通，佣金覆盖成本；自建执行 = 负收益工程 |
| F 数据 | **只拿结果** + 参考思路 | 行情数据 | AKShare/Tushare/TDX 免费；机构级（Wind/Bloomberg）成本>收益，无视 |
| C 模型 | **拿部分模块** | Qlib 开源框架 | 微软开源零成本，v5 已在使用 |
| B 证据 | **拿部分模块** + 参考思路 | ml4t/purgedcv 开源库 | 方法论开源，v5 已自建评估器（自建核心） |
| D 挖掘 | **参考设计思路** | 批量评估流水线、录用门槛 | 产出物封闭拿不到，只能抄模块设计 |
| E 风控 | **参考思路** + 轻量模块 | pyfolio 类指标 | 机构产品贵，个人需求简单，自建规则 |
| G 信号 | **选择性无视** | 无 | 产出物无价值；仅"外部策略当候选"例外（D 供给端） |

## 四、总原则

> **消费端（A/F）只拿结果，工具端（C/B）拿开源模块，决策端（D/E）抄设计思路自建，娱乐端（G）无视。**

## 五、关键瓶颈（当前唯一没有现成答案的格）

权重分布是畸形的：A/F/C/B 都是"输入和执行"侧，**真正决定收益率的 D（候选供给）和 B（择优）在自建侧**——而 8/8 已证：D 缺供给、B 无功效（9 候选 n_eff=1.88，候选同质，择优无统计意义）。

候选供给的三个口子：
1. **G 当候选**：外部策略（社区/论坛/机构文献）喂进比较池
2. **C 换层当候选**：Qlib/OSAP 的 ML 模型产出当候选（换层——唯一未证伪的方向）
3. **F 新数据当候选**：新数据源（基本面/另类）带来的新因子

## 七、定位修正（2026-08-08 晚讨论定论，替代旧"相对择优器"表述）

**定位链**：相对择优器（8/6）→ 淘汰器/证伪器（8/8）→ **程序性裁判系统**（8/8 晚，当前）

**为什么改**（依据）：
1. **证伪主义**（老板提出的核心论点）：证伪只需一条证据，证真一万条也不够——"选出最好的策略"= 证真 = 统计上不可达成；"淘汰不行的"= 证伪 = 可行且已做到（daily_pick 四重验证判死）
2. **n_eff=1.88**：候选同质时择优无统计功效（8/7 compare_pool 实证），"相对择优"这个名称暗示证真，本身有误导性
3. **成熟系统的设计哲学**：系统做"程序性裁判"（数据清洗/不可交易排除/回测/过拟合校验，把结果弄真），"好不好"交给用户判断——v5 学这个分工，不越权

**v5 的产出 = 输出四件套**（程序性裁判，不做价值性结论）：
1. **结果**：净值曲线、SR、MDD、换手、成本（统一日资金曲线口径，警惕按笔虚高）
2. **口径**：计算假设显式化（周期/成本/基准/年化算法），作为输出的一部分——比成熟系统更进一步（成熟系统口径是隐性裁判）
3. **可信度**：walk-forward OOS、DSR、MC、train/valid 相关性 r、alpha/beta 归因
4. **证伪判定**：程序性结论（"这个策略死了"），不越权做"推荐"

**两个坑**：
- 只输出数字不输出口径 → 滑向聚宽式流水线（价值在口径显式 + 可信度量化）
- 完全不做结论 → 无导向流水线（证伪判定必须保留）

**生产层含义**：daily_pick 每天推 Top5 = 价值性输出，与新定位冲突；按新定位应改为每天输出候选报告（表现 + 证据 + 证伪状态），用不用由老板决定——v5 不再背生产责任（独立决策，尚未执行）
