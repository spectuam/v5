## 1. 起点

38 因子等权选 Top5，5 年回测 WR 55%->test 51%。老板诊断核心问题是"注意力分散"（38 因子等权、5000 只全量排名、不看市场状态、不区分行业），方向是三层递进收窄注意力。

## 2. 最初批判（7 条）

1. **把"过拟合"误诊为"注意力分散"**：4 个点 drop 不支持三层重构
2. **三层递进参数空间乘爆**（最致命）：HMM(状态数+转移矩阵) + 概念轮动(数百概念) + 板块内自适应因子(38×N×权重) 参数膨胀 1-2 个数量级，样本量不变，过拟合更严重
3. **HMM 实盘滞后/不可解释/非平稳**：A 股状态切换快，HMM 确认滞后；状态不可解释；非平稳性使回测状态≠实盘
4. **概念动量有后视偏差**：Wind/同花顺概念分类事后添加，幸存者偏差，成分股重叠
5. **板块内选 Top5 统计接近随机**：小池子 alpha 被稀释
6. **WR 作为评估指标本身就错**：丢幅度信息
7. **4 个点 drop 可能不显著**：横截面相关使有效样本远小于 6250

**替代方案**：诊断 -> 决策门 -> 治疗（非线性，第一步是分叉点）。阶段 1 诊断先行（T1-T5），D1 判据选路径 A/B/C/都不做。

## 3. 诊断过程

### 3.0 环境探查

- v5 代码在 `/home/soso/v5/`：`build_ic_daily.py`（IC 构建）、`factor_decay_scan.py`、`line_bcd_backtest.py`（38 因子回测）、`backtest_validation.py`（3 因子 A/B/C 回测）

- 内存红线：WSL2 10G / user.slice MemoryMax=7G、MemoryHigh=6G；开了 dangerously-skip-permissions 没兜底，必须自己控内存

### 3.1 T1+T2 因子归因（推翻"因子衰减是主因"）

**方法**：从 `factor_ic_daily` 查 38 因子 IC，分 5 窗口（P1 选择期 06-15 / P3 核心资产 19-21 / P4 小盘量化 22-24 / P5 近期 25-26 / FULL）算 IR/t。纯 SQL 聚合，内存 <10MB。

**结果**：
- 因子没死：36/37 全段 |IR|>0.3，**21/37 近期 P5 仍强**，仅 **9/37 真衰减**
- 真根因=**因子选择窗口错位**：38 因子用 2000-2015 选（含 2007/2015 两轮大牛市），选择期 IR 普遍 0.6-0.8（虚高），回测期 2019-24 回归 0.2-0.5
- 9 个衰减因子：gtja191/alpha_008(-0.48)、alpha101/alpha_084(-0.47)、gtja191/alpha_026(-0.46) 等

**推翻**我最初假设"因子衰减是主因"--只部分成立（9 个衰减），21 个近期仍强。

### 3.2 T3a 路径 B 验证 + 内存工程（重点）

**目标**：equal_38 / equal_29（剔 9 衰减）/ equal_21（仅近期强）/ ic 加权 / ir 加权，VALID 2016-2020 + TEST 2021-2026 对比。

**内存教训**（跑通前炸了 3 次）：

| 次 | 方案 | 问题 | RSS |
|----|------|------|-----|
| 1 | 囤 38 因子值 | build_daily_panel 读长格式 df(6GB) + 囤 38 因子值 | 8.7G 炸 |
| 2 | 流式存盘因子值 | 算因子值前误释放 panel 非close 字段，compute_alpha 全失败 | 37 个 ERR |
| 3 | 释放移到 Phase1 后 | compute_alpha 临时累积，python 高水位 | 6.1G 接近杀 |
| 4 | **build_panel_light** | 按字段单独读 SQL+pivot+释放，峰值 3.7G | 跑通 |

**最终方案 build_panel_light**：每字段单独 `SELECT code, date, {field}` + pivot + `astype('float32')` + 释放 df，避免 6GB 长格式 df。峰值 3.7G（build 时）-> 释放非 close -> Phase2 读 pkl 2.2G。因子值存盘 float32 + 断点续传。

**跑前清单**（每次重跑前）：`drop_caches` + 停并发 timer（daily-report-v5 / m15-finalize）+ Monitor 盯 RSS>6G/错误。

**结果**（T3a SUMMARY）：

|--------|------|------|-------|
| equal_38 | 0.5513 | 0.5079 | 0.0007 |
| equal_29（剔衰减）| 0.5332 | 0.5163 | 0.0011 |

- **equal_38 复现老板的 55/51**（VALID 0.5513 / TEST 0.5079），回测正确
- 剔除衰减 TEST +0.84 个百分点（小幅）
- 静态 ic/ir 加权无效（用 2015 前 IC 给衰减因子高权，反受其害）

**弯路**：误读 `line_equal_results` 的 Top3/Top5/All 为选股数量，实际是**因子数量**（用前 3/5/全部因子，选股都是 Top5）。纠正：用因子越少越差（3 因子 WR=43.78%<50%），38 等权已是等权框架最优。

### 3.3 T5 显著性检验

**方法**：block bootstrap（block=20 天，5000 次），算 daily WR 的 95% CI，判断 drop 和提升是否显著。

**结果**：
- equal_38 drop 0.5513->0.5079（-0.0434）：VALID CI [0.5387,0.5661] TEST CI [0.4959,0.5222]，**CI 不重叠=显著**（WR 真衰减）
- equal_29 vs equal_38 TEST（+0.0085）：CI 重叠=**不显著**（剔除衰减的 WR 提升+0.85 是噪声）

**弯路**：脚本 verdict 逻辑 bug--`drop_overlap` 只查一个方向（`VALID上界>=TEST下界`），漏反向，输出"不显著"。实际 CI 不重叠=显著。手算修正 + 改脚本双向检查。

### 3.4 t6 净收益（已撤销）

**方法**：算 daily Top5 换手率 × 成本扫描（0.1/0.2/0.3/0.5% 单边），看扣成本净收益。

**结果**：换手率日均 85-86%，扣成本全负（0.1% 成本 TEST -24.5%，0.2% -67%）。

**撤销**：老板澄清"不考虑滑点/换手成本，是辅助选股系统，目标跑赢 80%"。t6 前提不成立，扣成本结论撤销。换手率 85% 数据保留但不作判据。

**弯路**：没问清定位就假设传统量化扣成本，白跑一圈。

## 5. 最终结论

### 5.1 数据汇总（正确指标 return_percentile）

| scheme | T_rp（分位） | T_WR |
|--------|-----------|------|
| equal_38 | 0.514 | 0.508 |
| equal_29（剔衰减）| 0.524 | 0.516 |
| equal_21 | 0.525 | 0.515 |
| ic_38 | 0.513 | 0.506 |
| ir_38 | 0.518 | 0.514 |

**目标 > 0.70，实际 51-52%，差 19 个百分点**。

### 5.2 核心结论

- **策略选股 alpha 接近随机**：收益分位 51% ≈ 中位数 50%，WR 50-55% 接近硬币边缘
- 真问题**不是**"注意力分散"（老板最初诊断）、**不是**"因子衰减"或"换手成本"（我最初假设），是**选股 alpha 本身稀薄**
- 剔除衰减/加权/三层递进/降换手都治不了--根因是因子 alpha 弱，不是架构/合成/换手

### 5.3 根因：因子源 alpha 稀薄（非数量少）

zoo 有 456 候选（alpha101 + gtja191 + qlib158），正交后 38 个，**数量不少**。但这些都是**经典公开因子库**，A 股市场效率提升后选股 alpha 已被套利消化--IC 还在（21/37 近期仍显著），但弱到选股分位只有 51%。不是选少了，是**因子源本身在当前市场 alpha 稀薄**。

### 5.4 对三层递进的最终判断

**不该做**。理由深化：最初批"参数膨胀过拟合"，最终发现更根本的是"**治不了 alpha 稀薄**"。复杂架构救不了弱因子。三层递进、路径 B（剔除衰减/加权）、降换手都是在现有 zoo 里打转，注定小幅。

### 5.5 突破方向

现有 zoo + 等权 Top5 达不到 70%。要突破得**换因子源**：
- 基本面（财务/分析师预期）
- 另类数据（资金流/龙虎榜/北向/舆情）
- 事件驱动
- RD-Agent 自动挖新因子

**不保证到 70%**--可能 55%、60%、也可能还是 51%。但这是唯一方向。

### 5.6 一句话总结

**这不是 v5 策略的 bug，是经典公开因子在当前 A 股被消化了。要跑赢 80%，得换更 hard 的 alpha 来源，而不是在现有 zoo 上调架构。**
