- stock_info / stock_sw2：两 db 都有，行数略不同（tdx 8579/5191 vs stock_data 5530/5342）

## 现状评估

- v5 生产/分析主用 **tdx_stock_data.db**（全历史 daily_kline + 因子IC + margin）
- stock_data.db 是旧辅助（backtest_validation 等老脚本 + kline_15m/财务独有）
- 重复表 + 脚本混用导致乱
