# 因子动量方向复盘与复现计划

> 日期：2026-07-30 凌晨
> 背景：从 DS 复盘建议 #6（周颗粒验证）出发，发现 v5 因子动量口径混淆，调研文献确认偏离，确定回文献口径复现方向。老板晚上想想，本文整理脉络 + 意见 + 步骤。

## 一、发现问题：口径混淆导致系统判错

从 DS 复盘建议 #6（周颗粒验证）深挖：
- 核实 `diagnose_result.json` 发现 week 颗粒度数据已存在：week P_TT=0.518 lift1.81 > month 0.402 lift1.41。老板"颗粒度太粗抹平信号"假设在诊断层被数据支持。
- 但系统锁了 month。根因：**口径混淆**--诊断层主链路硬编码 `granularity='month'`，1.4 颗粒度对比只旁路记录没接回 verdict；`K_LOCK=12`（注释"策略层锁定K"）被诊断层借用。验证层成本考量（"week换手成本吃光"）提前介入诊断层，锁了 month。
- 这是一例"系统判错"：因子动量被判"信号弱"是月颗粒度口径误判，不是因子真没信号。

## 二、口径校准：切 week 后诊断层判强阳性

重构 diagnose.py（线1尺子校准）：
- 颗粒度对比提前，数据驱动选 best_gran=week
- 主链路（MinTRL/AR1/转移矩阵/决策门A）全切 week 口径
- K_LOCK 解耦为 K_DIAG（诊断层独立参数）
- ISO 周对齐 factor_map

结果：决策门 A 判**强阳性**（原 month 判弱/归档）：
- AR(1)>0: 100%（>>GK 91%），显著 34/37
- 转移矩阵: P_TT 0.518 lift 1.81，χ²p=7.99e-250
- K扫描: week K=1 最优 0.405（佐证"因子有效期变短"假设）

但 phase2 选股级切 week 不保证训练翻正（agent 判断：训练负根因是因子 alpha 弱，非颗粒度）。

老板重新框定目标：**不是找合格策略，是把"历遍筛选组合+选优"方法内化进架构**；化学反应（因子非线性交互）是验证场。

## 三、调研文献：确认 v5 偏离文献口径

网络受限（WebFetch 被 enterprise security policies 挡），用 curl + 老板提供 GK 原文(md) + EL 方法论分析(DS做)。

**GK 原文核实**（ssrn-3300728.md）：
- "91%"有依据：59/65 因子 AR(1)>0=90.7%（Section 1 Fact 1）。agent 之前说"存疑"是没看正文。但库不同（GK 65 vs 我们 38）。
- TSFM 权重 = 收益 z-score（capped±2）× 因子收益
- 配置层：所有因子 timing 组合，不选股
- 最优窗口 1-1 月（Sharpe 0.84），1-12 月（0.70）

**EL 分析**（DS 做的逐句）：
- 因子收益 = top30%-bottom30% 多空
- TSMOM: w_f=r_f（收益>0做多<0做空），年化4.19%/t=7.04
- XSMOM: w_f=r_f-r̄（横截面），年化2.78%
- TSMOM 优于 XSMOM：利润分解显示交叉协方差项 -1.0%/年（横截面做多A做空B反而亏）
- 传导：因子收益自相关 -> β离散度 -> 个股动量
- IC ≠ 因子收益率（IC=排序能力，收益=多空组合收益，两者动量不等价）

**v5 偏离确认**：

| 维度 | 文献(GK/EL) | v5 |
|---|---|---|
| 信号 | 因子收益 | IC |
| 层次 | 配置层（因子多空组合） | 选股层（Top10合并） |
| 做多条件 | 收益>0（TSMOM时序） | IC Top-K（横截面） |
| 权重 | 收益本身/z-score | IC>0门槛 |
| 窗口 | 1-1月最优，1-12月 | K=12月 |

v5 是自创串联范式（IC选因子->选股），无文献背书。加 CPCV/PBO/DSR 防线仍收敛 0.50-0.53，方向上印证没用。

**v5 信号弱的可能解释**（EL 启发）：v5 的 Top-K IC 选股是横截面思维，按 EL 分解会损失"因子间正交叉预测"（交叉协方差 -1.0%/年）。这可能正是 v5 因子动量信号弱的根因之一。

## 四、我的暂时意见

1. v5 这套因子动量（IC 选股 + 决策门A + TSFM/CSFM 串联选股）偏离文献口径，是自创，收敛 0.50-0.53 印证没用。
2. 应该**回文献口径复现 GK/EL 的 TSMOM**（因子收益 + 配置层 + 12月），看在 38 因子 + A股数据上能否跑出文献级效果（GK Sharpe 0.84，EL 4.19%/t=7.04）。
3. 走通后再调 12月->12周（week 口径，呼应诊断层 week 强阳发现）。
4. 复现口径已明确（不闭眼，有原文依据）：因子收益（top30%-bottom30%多空）+ TSMOM（收益>0做多，权重=收益本身）+ 配置层组合 + 12月窗口。
5. 如果复现跑不出文献级效果，说明 A股/38因子库上因子动量本就弱（fable5"公开库alpha终结"硬约束），诚实接受。

## 五、计划实施步骤

1. **算因子收益时间序列**：每月每因子 top30%-bottom30% 多空组合收益（目前只有 IC，没有 decile 多空收益）。需 factor pkl + daily_kline。
2. **复现 GK/EL TSMOM**：12月窗口，因子收益>0做多<0做空，权重=收益本身，配置层组合所有因子。
3. **看能否跑出文献级效果**：对比 GK Sharpe 0.84 / EL 4.19%/t=7.04。扣成本（10bp）看 net。
4. **走通后调 12月->12周**（week 口径），看 week 是否改善（呼应诊断层 week 强阳）。
5. **对比 v5 原 TSFM**（IC选股），看文献口径是否优于原口径。
6. **决策点**：若复现跑出效果 -> 内化文献口径进架构；若跑不出 -> 诚实接受因子动量在 A股/38因子库上弱，归档。

## 七、month 复现结果（2026-07-30）

**TSMOM 复现跑出文献级效果**（sign等权，12月形成期，因子收益配置层）：

| 指标 | TSMOM复现 | v5原TSFM(IC选股) | 文献 |
|---|---|---|---|
| 训练夏普 | **1.31** | -0.023（负） | - |
| OOS夏普 | 0.69 | 0.557 | - |
| 全段夏普 | **1.02** | - | GK 0.84 / EL 0.98 |
| 全段t | 3.14 | - | EL 7.04 |

因子收益本身 t=4.66（因子有alpha，多空能赚钱）。

**结论**：复现训练夏普1.31（正且强），原 v5 IC选股训练 -0.023（负）。文献口径（因子收益+配置层）远优于 v5 原 IC选股口径，v5 偏离是错的，回文献口径能跑通且接近文献效果。老板怀疑对了。
