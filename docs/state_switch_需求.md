# 分状态策略切换 — 思路细化需求

> 编制：2026-07-22（cc 写思路，GLM 细化执行）
> 背景：v5 三轮验证全部收敛 0.50-0.53，长期找万能策略的路可能走不通

---

## 核心思路

**不预测市场会变成什么样。只判断市场现在是什么样，然后用对应的打法。**

三个步骤：
1. 用简单直观的指标定义市场状态（4-6 种）
2. 在每个状态里，对比不同打法的历史表现（动量/反转/低波/空仓）
3. 每天看一眼状态 → 切换对应打法

**不是策略内部自适应，是人在外面根据状态手动切换策略。**

## Phase 1：定义市场状态

### 1.1 状态指标（全部公开可得，日频）

| 指标 | 计算方式 | 含义 |
|------|---------|------|
| 涨跌比 | 全市场上涨家数 / 下跌家数 | 广度 |
| 涨停家数 | 当日涨停（>9.5%）股票数 | 投机热 |
| 连板高度 | 最高连板数 | 游资活跃 |
| 全市场换手率 | 成交额 / 流通市值中位数 | 活跃度 |
| 指数 20 日均线方向 | 上证综指 vs 20 日均线位置 | 趋势方向 |
| 指数波动率 | 上证 20 日收益率标准差 | 平稳/剧烈 |

### 1.2 状态分类（建议 4-6 种）

例如：
- **趋势上涨期**：指数在 20 日线上 + 涨跌比 > 1.5 + 波动率温和
- **震荡期**：指数在 20 日线附近 + 涨跌比在 0.7-1.5
- **恐慌下跌期**：指数在 20 日线下 + 涨跌比 < 0.5 + 波动率高
- **修复期**：恐慌下跌后开始企稳，涨跌比回升
- **妖股乱飞期**：连板高度极高 + 涨停家数暴增（和趋势上涨不同）
- **死水期**：换手率极低 + 波动率极低

### 1.3 验证

- 拉 2015-2026 A 股数据，每天打一个状态标签
- 每种状态占比多少？平均持续多久？状态切换频率？
- 产出：`state_labels.csv`（date, state）

## Phase 2：打法菜单

### 2.1 选股逻辑（全部基于 OHLCV，不换数据源）

| 打法 | 选股逻辑 | 持有期 |
|------|---------|--------|
| **动量 A**（强者恒强） | cum_ret_20 排序，选 Top10 | T+10 |
| **反转 A**（抄底） | cum_ret_20 排序，选 Bottom10（跌最多的） | T+10 |
| **低波 A**（趴着等轮动） | 20 日波动率排序，选最低的 Top10 | T+20 |
| **空仓** | 不选 | — |

### 2.2 每个状态 × 每种打法的历史表现

分状态回测：
- 状态持续期间内，每种打法跑一遍
- 评估指标：日均收益、收益分位、WR、盈亏比、最大回撤
- 找出每种状态下的最优打法

产出表格：
```

趋势上涨    | 0.58   | 0.42   | 0.50   | —    | 动量
震荡期      | 0.48   | 0.55   | 0.53   | —    | 反转
恐慌下跌    | 0.35   | 0.32   | 0.28   | 0.50 | 空仓
修复期      | 0.45   | 0.62   | 0.55   | —    | 反转
...
```

## 注意事项

- 状态定义不能过拟合——不要用未来数据决定状态
- 状态切换不要太频繁（如果一天一个状态，等于没分）
- 先写死阈值（如涨跌比>1.5），不要用 ML 自己学，保持可解释性
- 脚本放 `/home/soso/v5/state_switch/`
- 数据源：tdx_stock_data.db（daily_kline 表）
