### A3 四件套 schema 正式化 + 证伪判定
**问题**：四件套（结果/口径/可信度/证伪判定）是定位产出，但没 schema 化、证伪判定门槛没正式定义。

**做**：
1. 定义四件套 JSON schema（`branches/strategy_factory/four_piece_schema.json`）：
   - **结果**：净值曲线/SR/MDD/换手/成本（日资金曲线口径，警惕按笔虚高）
   - **口径**：周期/成本模型(固定vs真实)/基准/资金规模(100万/1亿)/年化算法 -- 显式列
   - **可信度**：walk-forward OOS / DSR(N_eff) / MC / train-valid r / alpha-beta 归因
   - **证伪判定**：显式门槛（见下）+ 程序性结论（"死了"/"未死"），不推荐
2. 证伪门槛定义（程序性，DSR 已按 N_eff 校正）：
   - DSR < 0.95 = 未死（过门槛≠好，只=没死）
   - MC 排除（不在 MCS 无法区分集合）= 证伪证据之一
   - forward OOS 衰减 > 50% = 证伪证据
   - 任一证伪证据 = 标"死了"，全过 = 标"未死，待 forward 积累"
3. 产出：四件套 schema + 证伪门槛表
