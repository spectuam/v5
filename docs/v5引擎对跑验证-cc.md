## 一、背景与目的

老板 8/9 提出：自写回测会不会有"没发现的弯路"（此前已走过 6:2:2 假验证、口径脱节等弯路）。
调研确认 RQAlpha（米筐开源，A 股涨跌停/停牌/t+1/最低佣金内置，活跃维护）→ 拿 tsmom_ls_K12 对跑。

对跑对象：tsmom_ls_K12 多头腿（TSMOM 信号选因子 × top30% 持仓，周频调仓，530 活跃周）。
**空头腿不参与**——A 股无普通卖空，原多空收益为纸面诊断基准。

## 三、实验矩阵与结果

### 十年对照（2016-2026，年化）

| 口径 | 年化 | 夏普 | MDD | 备注 |
|---|---|---|---|---|
| 我们理想（自写口径） | 16.1% | 0.73 | -32.7% | 无成本/无限制 |
| 100万·默认成本 | 2.1% | 0.34 | -19.5% | 成交 4.4 万笔，费占本金 22.3% |
| 100万·纯费率（无最低佣金） | 4.8% | 0.64 | -18.0% | 佣金 21.8万→2.2万 |
| 1亿·默认成本 | 7.0% | 0.45 | -40.3% | 成交 159 万笔，费占本金 35.4% |

**主结论：自写回测系统性高估 14 个百分点（年化）。**

### 三年归因闭合实验（2016-2018，1 亿资金，年化）

| 口径 | 年化 | 夏普 | MDD |
|---|---|---|---|
| 我们理想 | -0.5% | 0.31 | -31.2% |
| 1亿·默认（含涨跌停+停牌） | -9.7% | -0.43 | -40.3% |
| 1亿·无涨跌停（仅停牌） | -8.0% | -0.33 | -38.2% |

**归因分解（缺口 9.2pp，精确闭合，校验和 -9.16pp = 缺口）**：
1. 费用：**-2.41pp**（26%）——trades 实测（佣金 max(成交额×万8, 最低5元/笔) + 卖出印花税万5）
2. 涨跌停限制：**-1.72pp**（19%）——默认 vs 无涨跌停版净值差（精确实验）
3. 停牌+其余：**-5.03pp**（55%）——还原费用后剩余（停牌 2.3 万条拒绝为主，含分红时点/近似误差）

## 四、自写回测缺陷清单（按贡献排序）

1. **费用全缺**（2.4~3.5pp/年）：无成本模型
2. **停牌不可交易**（~5pp/年）：停牌订单被拒、复牌跳变未建模
3. **涨跌停不可成交**（1.7pp/年）：涨停买不进/跌停卖不出的机会成本
4. **最小手数/最低佣金 × 资金规模**：小资金下"等权 N 只"形态不可执行（247 元/只买不起一手，85% 目标未成交）
5. **未上市股票**：自写靠"查无数据跳过"无意处理，RQAlpha 严格拒绝

**本质：自写回测不是算错，是没建模成交现实——"任意价格任意量成交"假设。秒级计算时间的代价是这些全看不见。**

## 五、对 v5 的三条修正

1. **候选评估必须带资金规模口径**（四件套加"资金规模"项）——同一策略 100万/1亿是两种动物
2. **RQAlpha 纳入评估管道作第二引擎**——候选过四件套前先过真实引擎撮合
3. **候选形态约束**：等权 N 只需满足 N × 一手成本 ≤ 资金，否则不可执行

## 六、技术备注与教训

- RQAlpha 6.x CLI 无 -c 选项 → 用 Python API `rqalpha.run_file(strategy_file, config=dict)`，analyser 输出须显式配置 mod.sys_analyser.output_file
- 佣金配置在 `sys_transaction_cost` mod（stock_min_commission/stock_commission_multiplier），**不在** sys_simulation
- current_bar 撮合 = 收盘价成交（与我们口径一致，排除成交价假设差异）
- RQAlpha 分红处理完整（dividends.h5 + 前复权默认）——复权不是差异来源
- **长任务运行教训**（8/9-10）：stdout 重定向是块缓冲（日志不可见≠卡死）；判断推进用 /proc/PID/stat CPU 时间两次采样；跑前必须配进度可见/输出确认/超时保护/完成验证；参数化脚本要小心位置参数错位（e8_3y 曾因漏 nolimit 占位跑了 8 年错误窗口）
- 无涨跌停版运行时长不可控（成交翻倍 + 内存 5.1GB 近红线）——三年版用硬超时兜底

## 七、未闭合项（诚实）

- 三年窗口停牌贡献 5.03pp 中含"分红时点 + 近似误差"未单独拆出（可做但边际价值低）
- 十年 vs 三年窗口的比例外推未经严格验证（三年归因结构假设适用于十年）
- 涨跌停机会成本近似（十年版 1.7pp 来自日志×反事实，三年版 1.72pp 来自精确对照——两法一致，互为验证）
