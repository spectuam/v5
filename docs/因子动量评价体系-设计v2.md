## 0. 背景与定位

### 0.1 为什么有 v2

v1（综合讨论 §13）由 cc 合并 Fable5 两次回复做出五层设计，原则是"可复用 + 一步到位"。glm 对 v1 做了一次审阅，发现 4 个结构性问题：

1. 诊断层把"层层递进"（第一次回复精神）改成了"硬闸门串联"（AR(1) 不过全停），过脆
2. 层次归类错位：颗粒度在诊断/策略两边都出现；估值叠加放策略层；预登记放输出层（顺序倒了）
3. "一步到位"和"DSR 当前用不到"是真矛盾，不是表面矛盾
4. 输入校验用截面 corr（对 38 因子是空操作），AR(1) 对标基准失真（GK 是"为正 91%"非"显著 >50%"）

v2 是针对这 4 点的重构。**不是推翻 v1，是修正其落地路径**。

### 0.2 和 v1 的三个根本差异

| 维度 | v1 | v2 |
|------|----|----|
| 实现 | 五层一步到位 | 五层设计，**两阶段实现**（诊断先行，验证等阳性） |
| 校准 | 口径不分层 | **诊断相对值 / 验证绝对值分层**（暂缓 NW/成本/FDR 只对诊断层成立） |
| 估值叠加 | 放策略层 | **数据源依赖，当前跳过留接口**（OHLCV 无 PE/PB，做不了） |

## 1. 设计原则（v2）

1. **设计保留五层，实现分两阶段**——诊断层先行，验证层等阳性才投入。不在"信号存不存在都没确认时"就花 2-3 天搭 CPCV/PBO/DSR。
2. **校准口径分层**——诊断层走相对值（NW/成本/FDR 暂缓不阻塞），验证层走绝对值（成本层到位才给实盘判决）。两层用不同标准，不混。
3. **数据源依赖显式标注**——估值叠加需 PE/PB/盈利，OHLCV 没有，当前跳过留接口，不放进实现步骤。
4. **预登记前置**——参数网格和选择规则在跑 TSFM 之前锁定，不是参数选定后（事后登记=架空防过拟合）。
5. **规则随输入校准**——方法不变（如 AR(1)），通过标准随因子库大小标注（38 因子用 X，460+ 用 Y，不假装一套标准走天下）。
6. **可调参数写死**——block bootstrap 的 block 长度等用 Politis-Romano optimal block 固定，不留事后调整口子。

## 3. 各层设计细节

### 3.1 输入层

**输入**：因子 IC 时间序列（factor × date × 颗粒度）

**校验规则两条**：

**(a) 性质开关**：风格因子（低波/反转/动量/融资融券）可配置排除。
- [glm] 依据：第一次回复 Fable5 排除四风格因子，理由是性质不同（风格因子 vs 量价因子）且有额外数据依赖（融资融券数据）。这是**性质判断**，不应被相关性规则吞掉。
- 默认排除，开关可配置（扩库后若要纳入风格因子动量可打开）。

**(b) IC 时序去重**：用 IC 序列的 corr，**非截面 corr**。
- [glm] 关键修正：v1 用截面 corr>0.7，但 38 因子已截面去重过，此步对 38 因子是**空操作**。因子动量语境下的"重复暴露"是 IC 时序同涨同跌，应测 IC 时序 corr。
- 阈值待数据定（先跑 IC 时序相关矩阵，看分布再定阈值）。
- 对 38 因子明确标注"截面已去重，此步仅对扩库新增因子生效"。

**颗粒度**：week/month/quarter。month 为主用（回填后 139 切片，信噪比预期最优）。week 噪音大、quarter 样本少。

### 3.2 诊断层（阶段一，相对值口径）

**定位**：回答"38 因子库上因子动量信号存不存在"。相对值判断，NW/成本/FDR 暂缓不阻塞。

**四项检查**：

1. **MinTRL 检查**（入口）：
   - 训练段 2015-2022 = 96 个月，K=12（策略层锁定值）吃掉 12，有效 84 个月
   - block bootstrap 若 block=6，有效独立 block 约 14 个——偏少但可用
   - 不够（如有效 block < 10）则停，不进后续
   - [glm] 新增项，v1 缺失。Fable5 第二次回复明确提了 MinTRL。

2. **AR(1)**：每个因子月度 IC 一阶自相关。
   - 报**两档**：
     - AR(1)>0 占比（对标 Gupta-Kelly 59/65=**91%**，软信号）
     - 显著为正占比（硬信号，标注"严于 GK"）
   - [glm] 关键修正：v1 写"显著为正 >50% 对标 GK 59/65"，但 GK 的 59/65 是"AR(1)>0"（点估计为正，含不显著），不是"显著为正"。v1 对标失真。v2 分两档，对标基准修正。
   - **诊断信号，非硬闸门**：AR(1) 阴性≠因子动量不存在。因子动量可体现为排名延续（转移矩阵捕捉）而非 IC 水平延续（AR(1) 捕捉）。两者是不同的延续性概念。

3. **转移矩阵**：P(TopK->TopK) vs 基准率。
   - χ² 检验 + block bootstrap
   - block 长度 = Politis-Romano optimal block（写死，不事后调）
   - [glm] 第一次回复原创，第二次回复引用。

4. **颗粒度对比**：week/month/quarter 信噪比，锁定最优。
   - 预判 month。锁定后策略层不再扫 g。

**判定**（决策门 A，人判断）：综合 AR(1) + 转移矩阵。
- AR(1)>0 占比接近 91% **或** 转移矩阵 P(TopK->TopK) 显著 > 基准率 → 进阶段二
- 两者都阴性 → 阴性归档，关闭方向（对应 cc 预判"38 因子库信号弱"）
- **不设单点硬闸门**。人看过诊断报告后判断。

### 3.3 策略层（阶段二，需诊断阳性才启动）

**预登记（前置！）**：
- 参数网格：K=12（锁），k∈{1,3,5}，g=诊断层锁定值
- **两种规则同属文献体系**，预登记锁定参数空间 {TSFM, CSFM} × k∈{1,3,5}，**两规则都跑**，样本内夏普最高者（含规则类型）胜出：
  - **TSFM**（时序因子动量）：过去 K 期因子 IC 均值 → 符号为正看多该因子，符号为负回避。一刀切，阈值 IC=0。对标 Ma et al. (2024) A 股年化 9.91%、t=6.07
  - **CSFM**（横截面因子动量）：过去 K 期因子 IC 均值 → 按值从高到低排序，取前 k 个看多，其余静音。比较体系，不看绝对值看相对排名。对标 Ma et al. (2024) 同文横截面版本：A 股年化 7.02%、t=3.44、夏普 0.80
- 选择规则："选样本内夏普最高的参数组合 + 规则类型"
- 写入登记簿，带时间戳
- **N=3 × 2 = 6**（k∈{1,3,5} × {TSFM, CSFM}）。DSR 要 N 诚实计数
- [glm + ds] 关键补充（ds 7/27 审阅）：CSFM 是文献里 Fable5 没提的另一半。对小因子库天然适配——不依赖 IC 绝对值准确性，只比较相对排名，和"先走通相对值定位"的优先级一致。38 因子上 TSFM 的正负切换可能频繁（门槛附近横跳），CSFM 没有这个问题

**规则详情**：

| | TSFM（时序） | CSFM（横截面） |
|---|---|---|
| 逻辑 | 过去 K 期 IC 均值 > 0 → 放行 | 过去 K 期 IC 均值从高到低 → 前 k 个放行 |
| 阈值类型 | 绝对值（IC=0） | 相对值（排名前 k） |
| 受 IC 校准偏差影响 | 是（门槛附近误判） | 否（只看顺序） |
| 适配小因子库 | 弱（正负切换频繁） | 强（前 k 稳定） |
| 对标 Ma 2024 | 9.91% / t=6.07 | 7.02% / t=3.44 |

**估值叠加（Arnott）**：[数据源依赖，当前跳过]
- 收益分解为估值变动 vs 基本面变动
- 需 PE/PB/盈利数据，OHLCV 没有
- [glm] 关键发现：v1 放策略层，但 OHLCV 数据做不了。当前跳过，留接口待基本面数据接入。接受 Arnott 警告作为已知风险，不分解。

### 3.4 验证层（阶段二，绝对值口径）

**定位**：回答"因子动量策略值不值得实盘"。绝对值判断，需成本层到位才给实盘判决。

**四项**：
1. 时间切分：2015-2022 训练 / 2023-2026 一次性 OOS
2. block bootstrap 显著性（block 长度同诊断层）
3. PBO/DSR（N=6，TSFM+CSFM 各 3 个 k）：PBO<50% + DSR<0.95
4. 护栏：FM-1 月收益 vs 纯个股动量相关 ≤0.8（Ehsani-Linnainmaa）。超过 → 因子动量是个股动量马甲，废弃。

**口径标注**（关键）：
- 成本未接入时：判决 = 毛收益口径，标"待复核"
- 成本接入后：复核，给最终实盘判决
- [glm] 依据：暂缓三项校准只对诊断层成立。验证层是绝对值判决（扣成本后正 + 跑赢固收+4.5%），成本层没接时第三条判决是空的。强行给判决会出"诊断通过但验证层不可信"的尴尬。

### 3.5 输出层

- **预登记冻结确认**：参数选定前已登记，此步只确认，不改
- **决策门 A 提示**（新增）：诊断层结束后，报告内置"请老板选择：A. 进入阶段二 / B. 阴性归档"决策提示，附带 AR(1) 两档摘要 + 转移矩阵显著性摘要。强阳性标注（AR(1)>0 占比 ≥ 85% 且转移概率 CI 完全离开基准率 → 标"强阳性"）作为辅助参考
- **标准化报告**：ρ 序列图 + 转移概率 + 参数 + OOS 净值（成本前后）+ 护栏结果 + 与 Ma 2024（9.91%/t=6.07）对标 + **K 扫描结果**（K=1,3,6,12 AR(1) 对比，若最优在非 12 处则标注替换理由）
- **阴性归档**：阴性结果同样入库，关闭方向
- [glm] 新增"与 Ma 2024 对标"：v1 缺。跑出来若 TSFM 在 38 因子上只有 3%/t=1.5，对比 Ma 2024 的 9.91%/t=6.07，能定量说"38 因子库太小致信号衰减到 X%"。校准锚点。
- [ds] 7/27 审阅补充：K 扫描 + 强阳性标注 + 决策门提示，三项来自老板确认的补充建议
