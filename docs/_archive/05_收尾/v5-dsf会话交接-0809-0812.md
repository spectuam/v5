## 一、定位讨论最终收敛（8/9，接 8/8 晚）

**定位链**：相对择优器(8/6) → 淘汰器/证伪器(8/8) → **程序性裁判系统(8/8 晚定论)**。

老板 8/9 提出自己的表述并修正措辞，最终版（老板认可）：

> **v5 如实输出（含口径）净值/收益率等图形化内容，对可信度与归因做校验，用显式门槛给出"死/活"的附加说明——不推荐，用不用由老板定。**

关键要点：
- **口径是四件套里单独一件**（老板特别看重）：口径选择（周期/成本/基准/年化算法）本身就是隐性裁判——"如实输出"必须包含"把假设显式列出来"
- 证伪判定门槛叫**显式门槛**不是"简单门槛"（DSR 0.95 是按 N_eff 校正的；过门槛≠好，只=没死）
- 两坑：只输出数字不输出口径→聚宽式流水线；完全不做结论→无导向流水线
- 已写入 `docs/v5系统定位.md` §七（定位修正 + 四件套定义 + 生产层含义）

**输出四件套**：
1. 结果：净值/SR/MDD/换手/成本（日资金曲线口径，警惕按笔虚高）
2. 口径：计算假设显式化，作为输出一部分
3. 可信度：walk-forward OOS / DSR / MC / train-valid r / alpha-beta 归因
4. 证伪判定：程序性结论（"死了"），不越权推荐

### 实验结果

**十年对照（2016-2026 年化）**：
| 口径 | 年化 | 夏普 | 备注 |
|---|---|---|---|
| 我们理想（自写口径） | 16.1% | 0.73 | 无成本无限制 |
| 100万·默认成本 | 2.1% | 0.34 | 成交4.4万笔，费占本金22.3%（最低佣金5元×4.4万笔） |
| 100万·纯费率 | 4.8% | 0.64 | 最低佣金单独伤害：SR 0.34→0.64 |
| 1亿·默认成本 | 7.0% | 0.45 | 持仓 655→3476 只（86% 执行率），费用成主约束 3.5%/年 |

**三年归因闭合（2016-2018，1 亿，年化）**：理想 -0.5% → 默认 -9.7%，缺口 9.2pp
- 费用：**-2.41pp**（26%）trades 实测
- 涨跌停限制：**-1.72pp**（19%）对照实验精确
- 停牌+其余：**-5.03pp**（55%）还原费用后剩余
- **校验和 -9.16pp = 缺口 ✓ 精确闭合**

### 缺陷清单（自写回测，按贡献）
1. 停牌不可交易未建模（-5.0pp）
2. 费用全缺（-2.4pp）
3. 涨跌停不可成交（-1.7pp）
4. 最小手数×资金规模（100万下 247元/只买不起一手，85% 目标未成交）
5. 未上市股票（查无数据跳过，歪打正着）

**本质：自写回测是"任意价格任意量成交"的数学近似——不算错，算的是另一个世界。**

## 八、经验教训（本 session 踩的坑，已入记忆）

1. **长任务运行前必须**：进度可见（stdbuf/周期打点）、输出配置确认（RQAlpha 第一版白跑 40 分钟）、超时保护（Monitor+硬超时）、完成后验证
2. **日志不可见≠卡死**：stdout 重定向是块缓冲；判断推进用 /proc/PID/stat CPU 两次采样
3. **参数化脚本位置参数错位**：e8_3y 曾因漏 nolimit 占位跑了 8 年错误窗口
4. **报告口径必须查证**：8/8 报告"含成本"是没查证就写的（违反严谨准则的实例）
5. **无涨跌停版运行时长不可控**（成交翻倍+内存 5.1GB 近红线）——硬超时兜底
6. Monitor 进程匹配要用 comm 列过滤（bash 包装进程会误抓）
