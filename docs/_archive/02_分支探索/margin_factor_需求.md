## 背景

- v5 诊断（glm0720）：38 经典因子 OHLCV 选股，收益分位 51%，alpha 稀薄
- new_direction（翻倍股/动量）：OHLCV 动量天花板 0.55-0.625，长周期 0.40
- **结论：OHLCV 被榨干了。需要换数据源。**

融资融券是独立于 OHLCV 的信息源：
- 交易所官方 T+1 数据，akshare 稳定可拉，不受反爬限制
- 实证研究（聚源/广发/IMI）表明两融因子 IC 显著，且 Alpha 无法被传统因子（市值、估值、动量）解释
- 融资端（杠杆做多）和融券端（做空）都能提供独立信号

## Phase 1：数据拉取

### 1.1 数据源

akshare 接口：
```python
import akshare as ak
# 沪市某日全市场明细
df = ak.stock_margin_detail_sse(date="20231027")
# 深市
df = ak.stock_margin_detail_szse(date="20231027")
```

字段：信用交易日期、标的证券代码、融资余额(元)、融资买入额(元)、融资偿还额(元)、融券余量(股)、融券卖出量(股)、融券偿还量(股)

### 1.2 拉取方案

- 日期范围：2010-03-31（融资融券开通）至 2026-07-20
- 粒度：日频，每个交易日拉沪深两市全量
- 存储：写入 `~/ading/db/tdx_stock_data.db`，新表 `margin_detail`
- 脚本：`margin_pull.py`

### 1.3 注意事项

- akshare 按日返回全市场，需循环日期，每天 2 次调用（沪+深）
- ~16 年 × ~250 交易日 = ~4000 天，8000 次 API 调用
- **建议先拉最近 3 年（2023-2026）跑通流程，确认因子有效后再补全历史**
- 加 sleep 间隔防止限流（建议 0.5-1s）
- 断点续传：检查 db 中已存在的日期，跳过

## Phase 2：因子构建

### 2.1 基础因子

基于现有研究结论，构造以下因子。所有因子值越小 → 未来收益越高（RankIC 预期为负）。

#### 融资端（杠杆做多）

| 因子 | 公式 | 含义 |
|------|------|------|
| RZ_ratio | 融资余额 / 流通市值 | 融资盘占比 |
| RZ_buy_ratio | 融资买入额 / 融资余额 | 融资买入活跃度（聚源最强因子） |
| RZ_chg_1d | (融资余额_t - 融资余额_t-1) / 融资余额_t-1 | 融资余额单日变化 |
| RZ_chg_5d | 同上，5 日窗口 | 融资余额短期趋势 |
| RZ_chg_20d | 同上，20 日窗口 | 融资余额中期趋势 |
| RZ_net_buy | (融资买入额 - 融资偿还额) / 融资余额 | 融资净买入强度 |
| RZ_DTC | 融资比率 / 日均换手率 | 融资回补天数（IMI 因子） |

#### 融券端（做空）

| 因子 | 公式 | 含义 |
|------|------|------|
| RQ_ratio | 融券余额 / 流通市值 | 融券占比（IMI 最强融券因子） |
| RQ_chg_5d | (融券余量_t - 融券余量_t-5) / 融券余量_t-5 | 融券余量变化 |
| RQ_sell_ratio | 融券卖出量 / 融券余量 | 融券卖出活跃度 |

#### 综合

| 因子 | 公式 | 含义 |
|------|------|------|
| RZ_RQ_ratio | 融资余额 / 融券余额 | 多空力量比 |
| RZ_RQ_chg_5d | RZ_RQ_ratio 的 5 日变化 | 多空力量变化方向 |

### 2.2 因子处理

- 缺失值处理：融券余量可能为 0（无券源），RZ_RQ_ratio 填行业均值
- 极端值：1%/99% 分位数缩尾
- 行业中性化（可选，先不做，先看原始 IC）

## Phase 3：IC 分析

### 3.1 单因子 IC

- 方法：Spearman RankIC，因子值 vs 未来 T+N 收益
- horizon：T+1 / T+5 / T+10 / T+20
- 时间窗口：全段（2010-2026）、近 3 年（2023-2026）、逐年
- 指标：IC 均值、IC 标准差、ICIR、IC 胜率（>0 的比例）

### 3.2 对比基准

同期的 OHLCV 动量因子（cum_ret_20）的 IC，看两融是否提供增量

### 3.3 预期

- 融资买入额占比 IC 应在 -4% ~ -7%（参考聚源结果）
- ICIR > 0.3 视为可用

## Phase 4：回测验证

### 4.1 简单选股回测

- 选股逻辑：单因子排序，选 Top N（N=5/10/20）
- 持有期：T+5 / T+10 / T+20
- 评估指标：收益分位（return percentile，目标 > 0.70）、日均收益
- 测试期：2023-2026（先用近 3 年，跑通后再扩展）

### 4.2 对比

- v5 baseline（equal_38）：收益分位 0.51
- 翻倍股动量最优：0.55-0.625
- 两融因子能不能超过这两个？

### 4.3 相关性检查

- 计算两融因子收益序列 vs OHLCV 动量收益序列的相关系数
- 目标：< 0.3（低相关 = 独立信息源）
