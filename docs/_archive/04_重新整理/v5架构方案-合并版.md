## 一、双盲互证

cc 与 DS 独立调研（各 4 批联网核实），核心结论一致：相对择优器对、序数排名改集合、复利改 Sharpe+Calmar 硬筛、五路交集、口径对象化、不承诺赚钱。双盲互证，方向可信。

## 二、总判断

老板的"相对择优器"定位被文献支持（Romano-Wolf 借 Timmermann："equal-weighting...are hard to beat"）。3 项要改：
- ① 准确序数排名 -> MCS 无法区分集合
- ② 复利目标 -> DSR-adjusted Sharpe 排序 + Calmar 硬筛
- ③ 裸搜 460 -> 五路交集漏斗约束（顺序 E->D->B/A/C，统一）

## 三、能打败老板思路的（带 DOI，PBO 表述按 DS 修正）

1. **AMS 数学必然 + PBO 实证 55%**（Bailey et al. 2014, Notices AMS, 10.1090/noti1105）：N=460, y=10 纯噪声最优 IS 年化 Sharpe≈1.1、OOS=0；MinBTL 需 12.3 年，数据仅 10 年。**PBO 实证 N=8800 下=55%（选择程序不优于随机选择）**，非"趋近 1"（DS 修正：正式定义是条件概率，"趋近 1"原文无出处）。
2. **复利目标更糟**：path-dependent 锁定幸运路径，方差 > Sharpe；Kelly 对参数估计病态敏感（Wikipedia Kelly："仅概率完全已知时严格成立"）。
3. **量价 alpha 天花板**（+ A 股本土证据）：McLean-Pontiff 发表后衰减 58%；Hou-Xue-Zhang 65-82% 复现失败；东吴金工换手率因子 IC -0.072/IR -2.09；华泰 2019 以来量价整体不佳；Liu-Stambaugh-Yuan 2019 A 股 size/value 含壳价值特殊性。
4. **序数排名是错目标**：MCS/StepM/SPA/WRC 全输出"无法区分集合"不排名；Romano-Wolf"选唯一最优 bad idea，等权 hard to beat，trim 不用 pick"；PBO 原文"选最优过程 detrimental"。
5. **纯挖掘死、有先验活**：AlphaForge GP 在 CSI500 OOS IC 0.37%，纯挖掘天花板 2-4%，成熟因子 5-10%。
6. **MVO 不如等权**：DeMiguel 2009 RFS，1/N 击败 MVO+14 扩展，25 资产需 3000 月(250 年)才 beat 1/N。
7. **危机相关性飙升**：Longin-Solnik 2001 JF，bear 市相关性飙升，分散化危机期不成立。
8. **实证退化**：backtest Sharpe 1.26 vs live 0.31（4.1×）；316 因子多重检验后仅 5-8 个显著。

## 四、正路（9 条）

1. 目标改 **MCS 无法区分集合 + p 值**，不序数排名。
2. 选策略改**集合内等权 / trim + ensemble**，不排名选 Top-K。
3. **五路交集漏斗**约束搜索空间（顺序 E->D->B/A/C，见 §五）。
4. **DSR-adjusted Sharpe/Sortino 排序轴 + Calmar 硬筛**（剔除回撤超限），复利只做参考/二次检查。
5. 多重检验：**Harvey t≥3 + BH-FDR + DSR 逐策略 + PBO 总开关 + N 记账**（AMS 精神：不报告 N 的回测无法评估）。
6. CPCV 产出 **OOS 分布**比分布不比单点；**N_eff 用 PCA 估**（DSR 用 N_eff 不用 460）。
7. **forward OOS / paper trading** 是唯一真验证；CPCV 标注"同历史分布内、对未来无验证效力"。
8. 扩展谨慎：OSAP 复现 + post-pub OOS + long-only dilution；因子生成器用 Qlib+AlphaGen 当假设生成器（AlphaForge Table 1 做 sanity check）；组合用等权/Ledoit-Wolf 不用 MVO。
9. 能活因子有经济解释（动量/价值/规模/盈利/低 beta/质量）--和 v5 复现 TSMOM 方向一致。

## 五、五路交集漏斗（统一版 E->D->B/A/C）

融合说明：cc 原 E->A∩B->C->D（D 最后）；DS 原 D->B->A->C->E。FGX 原文警告"先单因子检验再 Lasso 会放大假阳性"（D 应先于 B/C）。融合：E 人工硬筛最前（便宜，先砍没解释的）-> D 控制存量 -> B/A/C 增量检验并行交集。

| 顺序 | 路 | 方法 | 文献 | v5 现状 |
|---|---|---|---|---|
| 1 | E 经济先验 | 人工标注有经济学解释 | Harvey 2017"门槛取决于经济合理性"；Arnott-Harvey-Markowitz 回测协议第一条=事前经济假设 | **缺** |
| 2 | D 独立性 | **double-selection Lasso**（Belloni-Chernozhukov-Hansen 2014）+ 正交化（Barra VIF 诊断，不过度正交化） | FGX 2020"简单 Lasso 选入≠真因子，先稀疏后检验" | **缺** |
| 3 | B 显著性 | NW-t + FDR 有效 N | 学术前沿标准 | 有（fdr_correct.py, factor_pers_B）✓ |
| 4 | A 强度 | IC 均值 + IR（IR 按 Grinold 定律 IR≈IC·√BR 校准，标注惯例来源） | 行业惯例 | 有 IC，**缺 IR** |
| 5 | C 形态 | decile 单调（**升级 Patton-Timmermann 2010 正式单调性检验**）+ 多空收益 t | Patton-Timmermann 2010 JFE | 有 decile.py/long_ic.py，**需升级正式检验** |

漏斗：E 硬筛（剔除纯挖掘）-> D 控存量（double-selection）-> B/A/C 增量交集 -> 通过的打分 Top-K 进比较。

**两坑（文献直接警示）**：
1. 交集漏斗无文献 canon 化--最近学术对应是 Harvey-Liu 框架（多重检验+经济先验+增量贡献），不是标准 pipeline。
2. A/C 惯例阈值与 B 的严格门槛（t>3.0）有口径冲突--统一用校准后的阈值。

## 七、可落地计划（阶段 0-5）

### 阶段 0｜认知对齐（不写代码）
接受 3 项"要改"+ 量价天花板定位。

### 阶段 1｜口径对象化（基础，DS 第一步）
- 策略配置 schema（JSON）+ `strategy_factory.py`（配置 -> 回测/生产可执行）
- daily_pick_v5 改读配置（等权投票 Top5 = 配置的一个实例）
- **产出**：生产/验证共用口径，碎片实验归位成配置实例

### 阶段 2｜比较框架重建（DS 第二步 + cc 补强）
- `compare_pool.py`：DSR-adjusted Sharpe + PBO + 集合输出 + N 记账 + 分时段 Spearman 稳定性
- 多策略横向比较（所有候选同口径同跑，不是 IC 选一个验证）
- CPCV 产出 OOS 分布（多 split 6/8/10）
- 实现 MCS：输出"无法区分集合 + p 值"
- **N_eff PCA 估**（DSR 用 N_eff 不用 460）
- 目标函数：DSR-Sharpe/Sortino 排序 + Calmar 硬筛 + 复利参考

### 阶段 3｜五路漏斗 + week 全链路（DS 第三步）
- 圆 E 经济先验标注表
- 圆 D double-selection Lasso + 正交化
- 圆 A 补 IR（Grinold 校准）
- 圆 C 升级 Patton-Timmermann 正式单调性检验
- factor_map 补 week 切片（诊断层已证 week P_TT 0.518 > month 0.402）
- 顺序：E -> D -> B/A/C 交集收敛 -> 候选池 -> 进阶段 2 比较
- **产出**：候选策略集合 + 诚实报告（含"无法区分集合"边界）

### 阶段 4｜forward OOS 真验证 + 生产接轨
- forward OOS / paper trading（唯一真验证）
- CPCV 标注"同历史分布内、对未来无验证效力"
- MinBTL 检查（10 年<12.3 年安全线，诚实标注）
- 候选集合内配置（等权/trim）-> 扣成本 OOS 复核 -> daily_pick 更新
- 决策门 B 升级为集合级

### 阶段 5｜扩展（谨慎）
- 数据层 OSAP（openassetpricing.com）+ Qlib Alpha158
- 因子接入：OSAP 复现 IS + post-pub OOS + long-only dilution 建模
- 因子生成器：Qlib+AlphaGen 当假设生成器，人脑经济先验过滤
- 组合：等权/Ledoit-Wolf 收缩，**不用 MVO**

## 八、最优先与下一步

阶段 1（口径对象化，基础）+ 阶段 2（比较框架）+ 阶段 3（五路漏斗）是核心。阶段 0 是前提。

**下一步**：进 plan mode 细化阶段 1+2+3 的具体实现（哪些脚本改、新增什么、怎么接现有 CPCV/PBO/DSR/FDR/NW/decile/long_ic）。
