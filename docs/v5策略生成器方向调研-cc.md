## 一、量化门槛抽象（讨论结论）

老板把量化门槛抽象为环节链，经讨论修正：

**老板原版**：数据、因子、口径、回测、筛选、验证、输出

**修正版**（补两个漏项 + 边界澄清）：
```
数据 → 策略(因子+内在口径) → 回测(含成交现实+外设口径) → 筛选 → 验证 → 输出(口径显式化)
              ↑                        ↑
         漏项A：策略生成/候选构建     漏项B：成交现实（成本/最小手数/涨跌停/停牌/资金规模）
```

- **漏项 A（策略生成）**：因子不是策略——因子经组合（TSMOM/等权/投票）、选股逻辑、再平衡设计才是候选策略。这是 v5 瓶颈所在（n_eff=1.88 候选同质、候选供给为零）
- **漏项 B（成交现实）**：成本/最小手数/涨跌停/停牌/资金规模——对跑 14pp 教训的核心。成本可并入口径，成交现实是独立建模层
- **筛选 vs 验证边界**：筛选=横向淘汰（候选间比较，MCS），验证=纵向证伪（时间/统计检验，walk-forward/DSR）
- **交易故意漏掉**（老板决定）：QMT 解决执行，v5 管评估

## 二、因子/策略/口径的重叠与分层（讨论结论）

三者重叠真实且有结构——根源是"旋钮视角"：

| 概念 | 本质 | 一句话 |
|---|---|---|
| 因子 | 单一信号 | 一个数值度量，不说买卖 |
| 策略 | 决策闭环 | 从信号到持仓的完整规则 |
| 口径 | 测量协议 | 怎么算的、跟谁比、什么假设 |

**核心洞察**：同一个参数（W=20、Top5、日频），作者手里叫"策略"（设计决策），评估者手里叫"口径"（测量协议）——视角切换时旋钮归属跟着变。

**分域框架**：
- **作者域**（策略定义）：因子集/组合/选股/周期/频率——作者负责，写进策略
- **评估域**（口径）：成本/基准/资金/时段/年化算法/PIT——评估者负责，声明在报告

落地映射：strategy_factory config = 作者域；compare_pool 口径参数 = 评估域。

**普通投资者混淆的根源**：普通人的"策略"= 参数缺失的决策规则（"买涨得好的"=动量因子未参数化；"赚了就跑"=止盈未参数化）→ 参数缺失 → 无法回测 → 无法证伪 → 永远不知道策略行不行。**因子和口径是量化世界的"语法"，把模糊策略翻译成可计算、可复现、可证伪的语言。**

## 三、策略生成器设想（老板提出，方向未定）

**定位**：类似"翻译软件"，双向：
- **正向**：自然语言 → 口径层&因子层 → 确认数值和运算符 → 形成可送进回测模块的策略（类似行情软件"条件选股"）
- **反向**：因子/策略 → 自然语言（如解释 alpha101 的某因子是低位翻转还是量能驱动）

**两半难度性质不同**：
- 正向 = 工程问题（LLM 翻译 + 参数确认）——EP004 已证明 LLM 能产策略，瓶颈在参数确认（"涨得好"→W=20 还是 30？）
- 反向 = 研究问题（因子语义归因）——alpha101 很多因子的经济含义至今无公认解读，语义无唯一答案

**与 v5 的关系**：策略生成器 = v5 生态的**候选供给工具**（老板用自然语言产候选 → 评估管道四件套证伪）——补上 8/13 记忆里"候选供给=范围外(v6)"的缺口。老板友好（不用写代码）。

## 四、调研记录：商业产品（正向翻译已商业化）

### Composer（Composer by SoFi，美股）
- 2020 成立，被 SoFi 收购；AI 原生零代码自动化交易平台
- 核心：Plain English 描述 → AI 生成完整策略（资产选择/权重/再平衡/风控）→ **60 秒回测** → 自动执行
- "Trade with AI"（2025-10）三模式：社区 3000+ 策略浏览 / 问卷引导 / 个性化构建
- 可视化无代码编辑器（拖拽、"如果…那么…"条件逻辑）
- 规模：日交易量 $2 亿+、累计 $280-370 亿、1800 万+ 订单、每月自动化交易 $25 亿+
- 定价：$32-40/月；限制：**美股/ETF/期权，无 A 股**
- 来源：tradersmagazine.com/departments/buyside/composer-introduces-trade-with-ai-to-enhance-investment-platform/ · sofi.com/invest/composer/ · 163.com 零代码量化交易报道

### 同花顺问财（i问财，A 股）
- 2006 成立，2015 自然语言选股日均 PV 破百万；2022 接入自研 Hithink 金融大模型
- 原理：自然语言语义理解 → 拆解多维选股条件（2.5 万+ 原子指标、数万标签/事件）→ 筛选
- 功能：条件选股/AI 智能选股（一句话组合多因子）/ **AI 回测**（"低PEG加高ROE组合近五年收益"→年化/回撤/超额曲线）/ 一句话生成策略+保存+每日自动执行 / 诊股查数 / 事件预测
- **开放接口**：get_iwencai（策略 init 中调用，结果存 context.iwencai_securities）、query_iwencai + pywencai 第三方桥接（每日限 1000 次无 token）
- 限制：免费额度极严（六七组条件即限流）；语义须符合金融用语模式；**以"选股条件"为主，非完整策略生成**（无权重/再平衡/风控生成概念）；黑盒（口径/因子层不透明）
- 来源：baike.baidu.com/item/i问财 · quant.10jqka.com.cn（get_iwencai/query_iwencai 文档）· aixq.cc/28961.html（问财 AI 评测）

## 六、为什么没人做"翻译器+裁判"方向（分析，部分为推理）

1. **多 Agent 是 LLM 舒适区**：一个 API 出 demo；翻译器要接数据层/因子层/回测层/口径层——工程基础设施，demo 糊弄不了
2. **传播逻辑：好看 > 有用**：ai-hedge-fund 5 万 stars 靠"巴菲特 agent 跟你聊"；"诚实验证策略会死"无传播性（负向结论不好卖，8/8 论证）
3. **绕开硬骨头**：生成决策 ≠ 验证决策——这些项目无 DSR/四件套/对跑/成交现实
4. **激励错位**：开源激励（stars/社区）→做炫的；付费市场（Composer）→做赚钱的执行闭环；"诚实评估"两头不靠
5. **诚实补充**：没人做也可能意味着商业不成立（裁判负向结论不好卖+候选池小；翻译器需求已被 Composer 以"美股+执行闭环"形态验证）

**对我们的含义**：我们做这个方向的理由不是"市场空白=机会"，是"我们需要"（翻译器+裁判对自己有用）——**自用系统的价值不依赖市场验证**（v5 从头到尾是自用逻辑）。

## 七、数据层调研记录：QMT 财务数据（老板拟 10 万开户获取）

### 版本体系（关键：版本比券商重要）
| 版本 | Python 接口 | MiniQMT | 财务数据 | 历史数据 |
|---|---|---|---|---|
| 标准版/普通版 | ❌ | ❌ | 仅简易 | 下载额度受限 |
| **专业版（要这个）** | ✅ | ✅ 外部 IDE 调用 | 完整接口 | 完整 Tick+大配额 |
| VIP 投研版 | ✅ | ✅ | 投研财务库+一键导全市场多年报表 | 取消 30 日区间限制 |

- **坑 1**：部分券商专业版**刻意关闭 MiniQMT 外部接口**——申请必须确认
- **坑 2**：专业版门槛乱象——有的 10 万起（国金/国信/中金财富/华西），有的 100 万+
- 门槛硬条件：20 个交易日日均资产≥10 万 + 风险测评 C4/C5 + **6 个月实盘记录**（老板已确认有）+ 客户经理白名单
- 来源：zhuanlan.zhihu.com/p/2002458110493742708（迅投版 vs 券商版）· licai.jiantou8.com 系列

### 财务数据能力
- 8 类报表：Balance/Income/CashFlow/CapitalStructure/Holdernum/Top10holder/Top10flowholder/Pershareindex
- **report_type 支持 announce_time（按披露日期）**——PIT 回测友好关键
- 字段：m_anntime=披露日期、m_timetag=报告期
- 接口：download_financial_data2（批量，建议单次≤50 只，进度回调）→ get_financial_data 本地缓存读取
- **历史深度无官方确定答案**（取决于券商数据服务端；示例 2015+ 可用）→ 需实测
- 来源：licai.jiantou8.com/user/guide_view_3408688.html · lianghuaba.net/thread-237.htm（xtdata 财务下载）· deepwiki.com/yslhzj/study_quanter（get_financial_data 文档）
